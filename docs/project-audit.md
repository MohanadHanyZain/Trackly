## Next.js 16-specific findings (from bundled docs)
- `LayoutProps<'/route'>` / `PageProps<'/route'>` are global helpers generated by `next dev`/`build`/`typegen`; `params` and `searchParams` are Promises and must be awaited.
- Cache Components enabled: data-dependent UI must be wrapped in `<Suspense>` or cached with `use cache` / `use cache: private`; random/timestamp values require `connection()` + `<Suspense>` or explicit caching.
- Route Handlers: GET handlers follow page caching model; `use cache` cannot be used directly in handler body — extract to helper.
- Server Actions: `'use server'`; sequential client dispatch; CSRF Origin/Host check; body size limit 1 MB; encrypted action IDs; `NEXT_SERVER_ACTIONS_ENCRYPTION_KEY` for multi-instance; `authInterrupts` experimental flag enables `unauthorized()`/`forbidden()` from `next/navigation`.
- Proxy (not middleware): single root `proxy.ts`, matcher-based; no `use cache`/`use server` inside proxy.
